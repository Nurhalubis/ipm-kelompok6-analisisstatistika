# Berkas peta

Kode di `laporan_IPM_kelompok6.qmd` membaca peta dari folder ini dengan susunan berikut:

```
peta/
├── Kabupaten/                 satu subfolder per provinsi berisi file .json per kab/kota
├── Provinsi/                  38 file .json batas provinsi
└── all_kabkota_ind.geojson    pelengkap untuk geometri yang kosong
```

1. **Kabupaten/** dan **Provinsi/**: salin kedua folder dengan nama yang sama dari
   <https://github.com/mashadinoor/Indonesia-Geojson-2026> (lisensi MIT).
2. **all_kabkota_ind.geojson**: berkas batas kab/kota Dukcapil 2019 dari
   <https://github.com/eppofahmi/geojson-indonesia>.

Berkas-berkas ini tidak disertakan di repositori karena ukurannya besar dan sudah tersedia di repositori sumbernya.
